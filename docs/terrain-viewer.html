建模方法與資料來源

既有 DSM → 保留高程基準並降採樣 → 排除 NoData 三角面 → 同日正射影像貼圖 → GLB。垂直倍率只改變顯示，點選讀值與下載模型均保留原高程。此為地表的 2.5D 網格，不包含岩壁背面或懸垂面的完整三維幾何。
